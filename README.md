# 轴承表面缺陷智能检测系统

基于深度学习的轴承/换向器表面缺陷检测系统，实现划痕、裂纹等常见工业缺陷的自动识别与分类。该项目为《制造智能技术》课程设计作品。

# 项目简介
在轴承制造过程中，表面缺陷检测长期依赖人工目视检查，存在检测效率低、漏检率不稳定、主观性强等问题。本项目设计并实现了一套基于深度学习的轴承表面缺陷智能检测系统，主要特点如下：
- 端到端检测：输入轴承表面图像，自动输出缺陷类型与位置
- 高精度识别：基于 YOLOv8 目标检测算法，实现划痕、裂纹等缺陷的精准定位
- 完整 Web系统：提供 B/S 架构的可视化操作界面，支持图像上传、实时检测、历史记录查询
- 工业场景适配：针对工业环境下的光照变化、图像噪声等问题进行优化

# 技术方向
本项目覆盖《制造智能技术》课程的以下技术方向：

| 技术方向 | 具体实现 | 在系统中的实际作用 |
|----------|----------|-------------------|
| 计算机视觉（深度学习目标检测）| YOLOv8 迁移学习 | 核心检测算法，实现缺陷的自动定位与分类 |
| 机器学习（图像分类/异常检测） | SVM + 特征提取 | 对检测结果进行二次验证，降低误报率 |
| 智能优化算法 | 遗传算法（DEAP） | 自动优化模型超参数（学习率、批大小等） |

# 数据集
本项目使用Kolektor Surface Defect Dataset 公开数据集。

- 数据集名称：Kolektor Surface Defect Dataset
- 来源链接：[Kaggle - Kolektor Surface Defect Dataset](https://www.kaggle.com/datasets/brumin/kolektor-surface-defect-dataset)
- 数据集描述：包含真实工业环境下金属表面的缺陷图像，主要用于缺陷检测与分类任务
- 数据规模：约 400 张图像，包含划痕和裂纹两类缺陷

# 数据预处理
运行预处理脚本完成以下任务：

python scripts/preprocess.py
预处理内容包括：

图像尺寸统一调整为 640×640 像素
标注格式从 XML 转换为 YOLO 格式（txt）
按 7:2:1 划分训练集、验证集、测试集
应用数据增强
